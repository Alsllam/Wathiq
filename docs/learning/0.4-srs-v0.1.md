# 0.4 — SRS v0.1

> **Phase:** 0 · **App:** docs · **Commit:** `step(0.4): write SRS v0.1 with use cases, FR/NFR and glossary` · **Date:** 2026-08-27

## What was built

[srs.md](../deliverables/srs.md) → `out/Srs.docx` (18 tables): IEEE 830 layout with constraints
C1–C4, six use cases (UC-01…UC-06, each with pre/post conditions and an alternative flow), 27
functional requirements across `FR-IDM / FR-DOC / FR-REM / FR-GDE / FR-AI / FR-DR`, 11 NFRs,
external interfaces, an ar/en glossary, and a traceability matrix back to the Vision's S/P/R IDs.

## Topics applied

| Topic | Where in the code | What I already knew it maps to (Angular / ABP / other) |
| --- | --- | --- |
| IEEE 830 section order | `srs.md` §1–§6 | MoD SRS documents; the difference is every row carries Source + Status columns |
| Testable "shall" wording | e.g. `FR-REM-002`, `FR-DOC-003` | Each maps to one unit test in Phase 1–2 (`ExpiryDate` validation, idempotent job) |
| Requirement IDs per module | `FR-<MODULE>-nnn` | Mirrors the six backend modules — a requirement's prefix says which ABP module owns it |
| Priority M/S/C | `Pri` column | MoSCoW — scope cuts happen by dropping C then S rows, never by editing M rows |
| Traceability matrix | last section | Like a route → component map: Vision S-item → UC → FR/NFR, checkable both ways |
| Unnumbered sections `{-}` | `# Document control {-}`, glossary, matrix | Pandoc heading attribute; fixes the 0.3 gotcha where front matter got §1 |
| Two-column "Field / Content" use-case tables | UC-01…06 | Pandoc pipe tables need a real header row — an empty `| | |` header renders oddly |

## The mental shift

The Status column ("Planned (P3)") turns the SRS from a one-time document into a **living
checklist**: every phase closes by flipping rows from *Planned* to *Implemented* and adding a
test reference. Also, the checkpoint questions in PLAN §3 are literally requirements
(`FR-DOC-003` = "30/02/2027 caught where?", `FR-REM-002` = "job safe to run twice") — the exam
and the spec are the same artefact.

## Gotchas hit

- Bash heredoc with mixed Arabic + apostrophes + `{-}` died with "unexpected EOF while looking
  for matching `'`"; wrote the file with the editor tool (same lesson as 0.1 — long bilingual
  Markdown does not go through bash heredocs on this machine).
- An empty pipe-table header (`| | |`) is legal but renders a blank bold row; used
  `| Field | Content |` instead.
