## The mental shift

An e2e suite is a **repository of browser truths** — every lesson unit tests structurally cannot
learn (cookies ignore ports, login pages autofill, the same Arabic word appears in two
components) either lives in a checked-in helper or gets re-learned by the next person at
debugging prices. That reframing settles what belongs in e2e: not coverage (units own that) but
the handful of full-stack paths whose breakage modes are invisible below the browser. And the
docs half completed a loop I didn't plan: writing the user guide forced user-language sentences
("nothing is saved until you confirm", "a countdown, not a frozen screen") that are *testable
claims* — three of them are literally assertions in the phase's specs. When the guide's
sentences and the tests' assertions coincide, both are probably true.

## Gotchas hit

- `import.meta` in the spec: Playwright transpiles TS specs as CJS, so `import.meta.url` throws
  and the run reports the misleading "No tests found" — the real error was a warning line above
  it. `__dirname` (CJS-native) for fixture paths.
- Pinned `@playwright/test@1.62` to match this machine's pre-provisioned Chromium (and
  `playwright-core` already in use); on the dev box `npx playwright install chromium` once —
  the version/browser coupling documented in the e2e README rather than left to be discovered.
- The 1x1-PNG fixture: generated as real PNG bytes, not an empty file — it must pass the
  server's MIME sniffing *and* the client's pre-checks; 70 bytes of honest image.

## Check yourself

1. Why does the e2e config auto-start the portal but *refuse* to auto-start the backend?
2. The happy path asserts the created number on the detail page AND back on the list. What
   distinct failure does each assertion catch?

<details><summary>Answers</summary>

1. Asymmetric cost and ownership: the portal is one deterministic command with a URL to poll -
   automation is free. The backend is a stateful environment (SQL, migrations, seeded users,
   certificates) whose setup differs per machine; pretending to own it would make the suite
   flaky and lie about its preconditions. Same split as OllamaFact: the gate is honest.
2. Detail: the create+upload round-trip worked and navigation landed on the right id (a wrong
   redirect or failed POST dies here). List: the collection query, pagination and row rendering
   include the new document (a caching bug, a broken refetch, or an owner-filter regression
   dies here while detail would still pass).

</details>
