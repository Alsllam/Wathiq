## The mental shift

For a solo-operated public service, the architecture rules that matter most are not technical
elegance but **what keeps one person safe and unblocked**: one deployable, free/local AI for
anything personal, and documents that regenerate from the repo instead of drifting. The six
modules exist mainly so each phase is a bounded lesson.
