## The mental shift

"No cross-module joins" was a sentence in PLAN §4; now it is a **structural fact**: separate
`DbContext`s make a join uncompilable, and the price is visible in the ERD as "(no FK)" edges
whose integrity the owning application service must guarantee. Seeing the reference backend's
single context with `#region` per module made the trade-off obvious — regions are a promise,
separate contexts are an enforcement. The schema also answers two checkpoint questions in
advance (idempotent reminders via a unique index; `ExpiryDate` validated in the domain).

## Gotchas hit

- Mermaid `sequenceDiagram` treats `;` inside a message as a statement separator → parse error
  on `A->>A: validate…; log…`. Replaced with commas.
- `npx @mermaid-js/mermaid-cli` works without a global install but the first run downloads
  Chromium (~1–2 min); `subprocess.run` needs `shell=True` on Windows for `npx.cmd`.
- Transparent PNG backgrounds look black in Word's dark preview — render with `-b white`.
- `Architecture.docx` is 610 KB because of `-s 2` (2× scale) PNGs; acceptable for print quality.
