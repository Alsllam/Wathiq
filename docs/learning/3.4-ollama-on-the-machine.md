## The mental shift

An environment step's deliverable is not "software installed" — it's **the system knowing
whether the environment is right**. Ollama couldn't be installed here, yet the step is
functionally complete: the health check makes its absence visible with guidance, the gated
smoke makes its presence provable with one env var, and the README makes the install
mechanical. The dev box run becomes a five-minute checklist instead of an exploration.
Second realization: the smoke test resolving the *keyed client from DI* is what turns "the
model answers" into "the system works" — a hand-built client would prove Ollama, but only
the composed resolution proves Wathiq.

## Gotchas hit

- Every model source is blocked in this container — github.com releases answer 403 through the
  proxy (while *git* operations ride a separate git proxy), ollama.com / registry.ollama.ai /
  huggingface.co don't resolve at all. Worth the five curl probes: "cannot" is now a recorded
  fact with evidence, not a guess.
- xUnit v2 has no runtime skip (`Assert.Skip` is v3) — the constructor-set `Skip` on a
  `FactAttribute` subclass is the version-safe idiom, and it reads better anyway: the gate is
  declared on the test, not buried in its body.
- A stale host from 3.1 was still holding port 44352 (found while verifying — the second
  port-squatter this phase). Killing by exact binary path patterns, in a command containing no
  plain occurrence of the name, is now the settled ritual.
