## The mental shift

The rule editor finally needed the pattern the checkpoint asks about — and it took until the
tenth screen-ish artifact: **seed-once from a resource is the legitimate effect on an edit
screen**. `computed` cannot express it (edits must diverge from the source) and an unguarded
effect is a bug (a refetch would clobber the user's work) — so the guard IS the design, not
defensive noise. The first draft used a `setInterval` poll to dodge the effect; replacing it
made the taxonomy click: derivation → `computed`, one-way sync out of Angular → 4.2's effect,
one-shot sync IN with divergence after → guarded effect. Everything else stays derived — the
timeline's entire visual structure is one pure function of two arrays and a date string.

## Gotchas hit

- `Intl.supportedValuesOf` failed only under *jest*: `tsconfig.base.json` still said
  `lib: es2020` (the build's tsconfig had newer settings, hiding it). Bumped the base to
  `es2022` — one workspace, one language level.
- `DatePipe` + locale-as-argument threw NG0701 in specs (`Missing locale data for "ar"`) —
  registered in production by our provider, absent in TestBed. Registered at spec module scope.
- The post-save `expectOne` for the reload found no request: `resource.reload()` issues its
  fetch through effects, so the test needed a `detectChanges()` between flush and expect — the
  4.3 ordering lesson wearing a new hat.
- `upcoming-list` turned out to be **windowless** (all Pending reminders, any horizon) — checked
  the app service before writing the e2e instead of assuming a 90-day window; the timeline for
  2036 documents exists precisely because of that.

## Check yourself

1. Why does `buildTimeline` take `todayIso` as a parameter instead of calling `new Date()`
   inside, and where is the analogous decision in the backend?
2. Classify these three by the taxonomy: (a) `dir` from `lang`; (b) writing `<html dir>`;
   (c) filling the rule editor from the GET. Name the guard each needs.

<details><summary>Answers</summary>

1. Determinism at the seam: the caller owns "now" (the component passes today, tests pass a
   fixed date) - the same reason `ReminderScheduler` takes the clock through `TodayIn(tz, utcNow)`
   instead of reading `DateTime.Now`: time is an input, not an ambient.
2. (a) `computed` - pure derivation, no guard needed. (b) `effect` - state leaving Angular's
   world; its "guard" is idempotent writes. (c) guarded seed-once `effect` - sync INTO editable
   state; the guard is the seeded flag, protecting divergence (user edits) from the source
   refetching.
